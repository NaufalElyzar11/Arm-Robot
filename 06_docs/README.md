# 06_docs — Dokumentasi & konten

- **`DESIGN.md` — dokumen rancangan utama** (tujuan, keputusan, analisis beban, rencana digital twin, roadmap, risiko).
- `build_log.md` — catatan harian: apa yang dikerjakan, masalah, solusi (bahan utama konten & portofolio).
- `calibration.md` — prosedur kalibrasi nol sendi.
